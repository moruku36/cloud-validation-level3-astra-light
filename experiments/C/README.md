# LEVEL3-C 検証計画・実施概要

本ディレクトリは、クラウドアーキテクチャ検証 LEVEL3 における **Phase C（IaC実装・実機デプロイ・カオス／障害試験・条件変更検証）** の成果物および追跡記録を管理します。

---

## 1. Phase C の位置づけと目的

Phase A（AWS単一設計）、Phase B（3社比較・選定設計・評価引継ぎ）を経て、実機環境（または制御された検証環境）での再現性確認、障害復旧（RTO/RPO）の実証、および4つの変更シナリオに対する耐性を検証します。

### 全体の中でのPhase C

---

## 2. Phase C 検証フロー（C-0 〜 C-10）

Phase C は以下の順序で独立した検証ステップとして進行します。各ステップの詳細は [B-3 C検証計画](../B/B-3/c-validation-plan.md) に定義されています。

| 工程 | 検証項目・対象 | 主な目的と合否基準 | 構成タイプ |
|---|---|---|:---:|
| **C-0** | **承認・前提確定** | 実験予算上限、保持期限、操作許可範囲、停止閾値の人間承認 | 文書 |
| **C-1** | **隔離環境再構築** | IaCによる初期環境構築、無承認apply不可、秘密分離、状態管理 | L (機能確認) |
| **C-2** | **機能・セキュリティ** | 内製認証、画像アップロード制限、SESメール送信制御、Canary | L (機能確認) |
| **C-3** | **負荷・片AZ容量** | 通常10 RPS / ピーク100 RPS（15分 9:1）、単一AZ縮退時の残容量検証 | H (本番相当) |
| **C-4** | **無人復旧・制御DB障害** | プロセス/タスク/DB障害からの自動復旧（RTO 30分・RPO 5分・300秒安定） | H (本番相当) |
| **C-5** | **論理破損・退会再削除** | 20GB DBの特定時点復元（4h暫定目標）、退会データ再削除・台帳照合 | H (本番相当) |
| **C-6** | **国内リージョン復元** | 大阪リージョンへのDR資材転送・東京依存遮断状態でのコールド復旧 | H (本番相当) |
| **C-7** | **変更シナリオ1: 1000 RPS** | 通常負荷10倍・登録100万人シナリオに対するスケール検証 | H＋増強 |
| **C-8** | **変更シナリオ3: 月額2倍** | 基準月額×2の感度分析、コスト削減施策と限界・再選定分析 | 分析文書 |
| **C-9** | **変更シナリオ4: Public IP禁止** | Private化（NAT/VPC Endpoint経由）への変更影響とコスト・経路検証 | H (Private) |
| **C-10** | **保守引継ぎ・最終Cleanup** | スキーマロールバック検証、保守体制への引継ぎ演習、全リソース完全削除 | L＋監査 |

> **構成タイプ凡例**:
> - **L (Low / 機能確認用)**: 1タスク / 単一AZ、小型DB。機能・権限・再構築の確認用。
> - **H (High / 本番相当)**: 2AZ Fargate 2タスク＋RDS Multi-AZ。HA・負荷・障害復旧の実証用。

---

## 3. 変更シナリオ4項目の検証対応

補足要件で規定された4つの必須変更シナリオとPhase C各工程の対応関係：

1. **ピークリクエスト10倍 (1000 RPS)**: C-7 にて実施。タスク増強・ボトルネック特定。
2. **制御可能なDB障害**: C-4 にて実施。Multi-AZ自動フェイルオーバーと接続断復旧の挙動実証。
3. **月額換算費用2倍のケース分析**: C-8 にて実施。課金支出を発生させず、単価・使用量メトリクスから感度分析を実施。
4. **Public IP禁止シナリオ**: C-9 にて実施。タスク・LBのプライベート配置とエンドポイント要件の設計・検証。

---

## 4. 費用管理と完全クリーンアップ原則

- **短期検証基本予算**: **12,495 円 ＋ U**（50%安全バッファ込み **18,742 円 ＋ U**）
- **完全削除原則**:
  - 各工程（C-1〜C-10）完了時、および日跨ぎ前に課金リソースを原則完全削除。
  - 停止（Stop）のみで無課金と判断せず、ディスク、IP、LB、NAT、DB、バックアップ、ログの残存を確認。
  - KMSキーなど即時削除不可の例外は「削除待機（Pending Deletion）」として台帳管理。
