## 1. アクション・課題管理記号

| 記号 | 名称 | 意味・役割 |
|---|---|---|
| **H** | **Human Decision（人間判断待ち）** | AI単独では決定できないビジネス・法務・体制上の意思決定（メール保存範囲、PITR期間、内製運用体制など）。 |
| **D** | **Design Feedback（設計限定差戻し）** | B-3レビューで指摘された設計不整合・根拠不足を解消するための再設計タスク。 |
| **E** | **Experiment Validation（実証試験待ち）** | 実環境でのデプロイ・試験（T01〜T16）を待つ検証項目。 |
| **REQ-xx** | **Requirement ID** | 要件定義ID（[REQ-01〜REQ-24](requirements.md)）。 |
| **F01〜F11** | **Findings（レビュー指摘）** | B-3評価レビューで抽出された11件の不合格理由・設計課題（[review.md](../experiments/B/B-3/review.md)）。 |

## 3. コスト・検証固有の記号

| 記号 | 意味 | 補足説明 |
|---|---|---|
| **＋ U** | **Uncertain / Variable Costs（未精算費用）** | 基本月額見積もり（AWS: 83,248円）に含まれない従量・変動費。具体的には以下を含む：<br/>- CloudWatch Logs / メトリクス流量<br/>- Route 53 クエリログ・追加ヘルスチェック<br/>- データ転送料の超過分（200GB超）<br/>- S3 バックアップ・バージョン保持増加分<br/>- 追加のセキュリティ監査・WAFルール課金 |

## 4. 安全ガード・IaC用語

| 用語 | 意味 |
|---|---|
| **Preflight** | クラウド接続前、または変更適用前に、前提条件（リソース名の非重複、ロール存在、リージョン等）をread-onlyで確認する事前検査。 |
| **Private Binding** | AWSアカウントID、実行プロファイル、秘密ARNなどの実値をリポジトリ公開コードから除外（repo外の暗号化領域にバインド）する安全機構。 |
| **Bootstrap Stack** | TerraformのStateバケット、KMS暗号化鍵、操作用IAMロールを管理するローカル初期化スタック。 |
| **Fixture Stack** | 実験対象となるテスト用S3バケット等のリソーススタック（Bootstrap完了後にS3 Remote Backendで管理）。 |
| **Canary** | 意図的に権限拒否（AccessDenied）が発生することを確認するための安全なテスト用合成オブジェクト。 |
